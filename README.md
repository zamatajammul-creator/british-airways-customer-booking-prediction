# British Airways Customer Booking Prediction

## Project Overview
This project uses Machine Learning to predict whether a customer will complete a booking based on travel and booking information.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Building
5. Cross Validation
6. Feature Importance Analysis

## Model
Random Forest Classifier

## Results
Achieved strong predictive performance using cross-validation and classification metrics.

- Data Analysis
- Machine Learning
- Predictive Modeling
